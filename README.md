# La Tavola Italiana 

A responsive Italian restaurant website built using HTML, CSS, and JavaScript.

## Features
- Restaurant landing page
- Menu with food categories and images
- Interactive shopping cart with quantity controls
- Delivery partner links
- Delivery form with order confirmation

## Technologies Used
- HTML5
- CSS3
- JavaScript

## Live Demo
[Visit La Tavola Italiana](https://khushijha29.github.io/la-tavola-italiana/)

## What I Learned
- Structuring a multi-section website using HTML
- Styling layouts and components with CSS
- Adding interactivity using JavaScript
- Deploying a static website using GitHub Pages
